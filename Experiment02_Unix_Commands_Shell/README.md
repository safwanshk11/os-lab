# Experiment 02: UNIX Commands and Shell Programming

## Aim
To study and execute UNIX commands and develop shell scripts.

## Shell Scripts Included
1. `greatest.sh`: Finds the greatest among three numbers.
2. `factorial.sh`: Finds the factorial of a given number.
3. `oddsum.sh`: Calculates the sum of odd numbers up to N.
4. `fibonacci.sh`: Generates Fibonacci numbers up to N.
5. `calculator.sh`: Implements an arithmetic calculator using a case statement.
6. `largestdigit.sh`: Finds the largest digit in a given number.
7. `palindrome.sh`: Checks if a string is a palindrome.
8. `reverse.sh`: Finds the reverse of a given number.
